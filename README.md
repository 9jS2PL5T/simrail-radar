# 🚆 SimRail Radar

**Train & Dispatcher Encounter Finder for SimRail – The Railway Simulator** *(PL / DE / EN)*  
Not just another live map: **SimRail Radar** analyzes live timetables, routes, and speeds to calculate **which free AI trains will have the most real player encounters and active dispatchers** ahead of them.

### 🇬🇧 English
**What does it do?**
* Finds free AI trains with the highest number of upcoming player encounters (oncoming traffic, overtaking, crossings) and active player signal boxes (dispatchers).
* Live map highlighting your selected/active train, oncoming player trains, overtaking trains, and occupied signal boxes.
* Filter recommendations by owned rolling stock DLCs and choose your priority (*Balanced*, *More Player Trains*, or *More Signal Boxes*).

**How to use (Windows):**
1. Download **`SimRail_Radar.exe`** from the [**Latest Release**](../../releases/latest).
2. Double-click `SimRail_Radar.exe` – your browser will open automatically. *(Note: On first launch, Windows SmartScreen may show a warning because the `.exe` is unsigned. Click **More info → Run anyway**.)*
3. Alternatively, run `simrail-radar.pyw` directly with Python 3 (zero third-party dependencies required).

### 🇵🇱 Polski
**Co potrafi ten program?**
* Wyszukuje wolne pociągi (AI) z największą liczbą nadchodzących spotkań z innymi graczami (ruch przeciwny, wyprzedzanie, krzyżowania) oraz obsadzonymi nastawniami.
* Mapa na żywo pokazująca wybrany/aktywny pociąg, pociągi graczy oraz obsadzone nastawnie.
* Filtrowanie według posiadanych dodatków DLC oraz wybór priorytetu (*Równowaga*, *Więcej pociągów graczy*, *Więcej nastawni*).

**Instalacja i uruchomienie (Windows):**

3. Możesz też uruchomić bezpośrednio plik `simrail-radar.pyw` za pomocą Pythona 3 (bez dodatkowych bibliotek).

### 🇩🇪 Deutsch
**Was kann das Tool?**
* Findet freie KI-Züge mit den meisten bevorstehenden Spieler-Begegnungen (Gegenverkehr, Überholungen, Kreuzungen) und besetzten Stellwerken (Fahrdienstleitern).
* Interaktive Live-Karte mit Fokus auf deinen aktiven oder ausgewählten Zug samt Farbcodierung für Begegnungen.
* Filterung nach eigenen Fahrzeug-DLCs sowie Prioritätswahl (*Egal/Ausgewogen*, *Mehr Spieler-Züge* oder *Mehr Stellwerke*).

**Start unter Windows:**
1. Lade **`SimRail_Radar.exe`** unter [**Releases**](../../releases/latest) herunter.
2. Starte `SimRail_Radar.exe` per Doppelklick – das Radar öffnet sich automatisch im Browser. *(Hinweis: Beim ersten Start einer unsignierten Community-`.exe` zeigt Windows SmartScreen ggf. einen Hinweis – klicke auf **Weitere Informationen → Trotzdem ausführen**.)*
3. Alternativ lässt sich `simrail-radar.pyw` direkt mit Python 3 starten (keine Zusatzpakete nötig).
